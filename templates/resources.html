Getting Started

NetSentinel operates as a localized Flask application. To begin monitoring your network:

  • Install the required dependencies via pip install -r requirements.txt
  • Ensure you have Npcap (Windows) or libpcap (Linux) installed for packet sniffing.
  • Run python app.py to boot the local server.

The AI Threat Engine

The AI Engine analyzes live packet statistics without sending sensitive payloads to external servers. It looks for anomalies in:

  • Unusual port scanning activity (Nmap signatures).
  • High-frequency outbound data transfers (Potential exfiltration).
  • Known malicious MAC OUI vendor signatures.

Active Firewall Integration

When you click "Block IP" in the dashboard, NetSentinel interfaces directly with the Windows Defender Firewall via PowerShell commands to instantly drop all incoming and outgoing packets to that address.
